# WolfOS roadmap and acceptance gates

P0: Rust no_std x86-64 kernel; QEMU serial, memory-map and framebuffer smoke checks.

P1: CPUID (merged); physical frame allocator (merged), scalable HHDM-backed bitmap (merged); GDT/IDT, CPU exceptions (merged), paging map/unmap and #PF (merged), PCI read-only discovery (merged), ACPI RSDP read-only validation (merged); RSDT/XSDT checksum validation and MADT CPU count (merged), Limine AP Rust handshake (merged); AP-local GDT/TSS/IST/IDT, WolfOS-owned AP stacks and verified SMP CPU work (merged); cooperative exactly-once kernel job queue (merged); per-CPU task queues and Ready/Running/Blocked/Finished lifecycle (merged); BSP-only cooperative assembly context-switch proof (merged); three stack-backed TCB execution contexts and yield/block/wake test (merged); generic indexed 16-TCB context batch (merged); 256 BSP-owned stack-backed TCB proof with strict 4 MiB stack bank (merged); real per-CPU context switching with private kernel stacks (merged).

P2: Ring 3 user mode, syscalls, ELF loader, init, scheduler and RAM-backed file system.

P3+: graphics, audio, networking, tested driver packages, secure updates with rollback.

Windows and Steam applications are aspirational milestones: Linux ABI / POSIX, Win32/NT API compatibility, Vulkan graphics, DRM and anti-cheat restrictions. No universal compatibility promise.

No milestone can be marked complete without reproducible build and run evidence.

P1 topology validation (merged): isolated QEMU MADT tests with 1 and 4 virtual CPUs. APs execute verified Rust work on dedicated stacks, with independent GDT/TSS/IST/IDT and real per-CPU cooperative kernel context switching. APs park with interrupts disabled after the boot proof. No preemptive or fully dynamic SMP scheduler yet.

P1 legacy timer (merged): isolated single-BSP PIT/8259 IRQ0 delivery, PIC EOI and tick-gated **safe-point/cooperative** dispatch between kernel contexts in QEMU. This is not asynchronous task preemption.

P1 local APIC discovery (merged): per-CPU read-only IA32_APIC_BASE MSR and CPUID APIC-ID validation for BSP/APs; temporary, read-only uncached BSP xAPIC MMIO mapping for ID/version observation. Normal kernel boot still does not enable APIC timer IRQs.

P1 xAPIC timer hardware proof (merged, PRs #26–#31): pure LVT/divisor/vector validation, masked timer programming plan and EOI/SVR validation, plus *isolated QEMU smoke-mode* writable MMIO, genuine periodic BSP APIC timer interrupts and matching EOIs. The IRQ path passed 1- and 4-vCPU QEMU tests; no AP timer delivery is claimed. Test tears down the temporary mapping, masks LVT and leaves CPU interrupts disabled.

P1 reference calibration proof (merged, PR #32): isolated BSP PIT channel 2 terminal-count polling (~20 ms) measures the decrement of a masked xAPIC one-shot timer, then uses checked integer arithmetic to estimate a 100 Hz periodic initial count. Full QEMU acceptance verifies both calibration results and actual IRQ/EOI delivery with 1 and 4 vCPUs (Actions #213, 14 October 2026). PIT2 does not establish general-purpose clock precision, drift bounds or cross-hardware portability.

P1 xAPIC tick-gated cooperative context proof (merged, PR #34): reuse the two independent stack-backed Rust execution contexts from the PIT smoke test; each APIC timer epoch permits one voluntary yield on the BSP. Both calibrated and uncalibrated xAPIC timer QEMU smoke flavors require six strictly increasing IRQ epochs, six dispatches and twelve RSP switches on 1 and 4 vCPUs. The IRQ handler only publishes an atomic counter and EOI; **this is NOT IRQ-frame preemption**.

P1 read-only xAPIC interrupt-frame observation (merged, PR #35): an independent non-yielding BSP workload is interrupted by the xAPIC timer at least four times; the IRQ handler records a copy of its first architectural RIP/RSP/CS/RFLAGS values and the in-flight work count. The work must resume and advance after the first IRQ; 1- and 4-vCPU QEMU regressions validate the frame's CPL0, stack alignment and saved IF. **This captures no GPR/SIMD state, performs no scheduler handoff, and never restores a new context.**

P1 complete-GPR trap-frame layout preflight (merged, PR #36): fixed `repr(C)` x86-64 ring-0 frame offsets for 15 general registers and the five architectural IRQ return fields, with reject-on-invalid stack bounds, selector and IF. This is a host-tested **contract for a future assembly entry**, NOT a verified hardware handler, full processor-state save, task switch or preemptive scheduler. A real entry/exit stub, FP/SIMD state policy and QEMU involuntary handoff are still required.

P1 xAPIC assembly GPR entry/IRETQ proof (merged, PR #37): isolated QEMU APIC smoke replaces the compiler-generated x86-interrupt timer entry with a hand-written kernel-CPL0 assembly interrupt-gate stub. It pushes/pops 15 general-purpose registers in the defined trap-frame ABI, passes a temporary frame to a Rust EOI/atomic-only handler with stack realignment, and returns to the **same interrupted context** via IRETQ. Acceptance requires matched real IRQ/EOI/trap counts, non-yielding worker completion, and existing cooperative dispatch on 1- and 4-vCPU calibrated/un-calibrated QEMU. **No task involuntarily switches to another task.** Floating-point/SIMD, per-task kernel stack ownership, task-state/CR3/TLS and robust IRQ-safe dispatch are still missing.

P1 live all-GPR preservation regression (merged, PR #38): a dedicated BSP-only assembly worker loads distinct sentinels into all fifteen general-purpose registers, then performs a bounded non-yielding loop. A real local xAPIC timer interrupt must capture exactly those values in the assembly trap frame; the entry saves/restores every GPR and IRETQs to the **same** worker. Full calibrated/un-calibrated 1/4-vCPU QEMU regressions require at least four valid observations and zero mismatches, independently of the earlier read-only Rust worker frame proof. This does not prove SIMD/FPU state preservation or involuntary task handoff.

P1 isolated BSP involuntary kernel preemption proof (merged, PR #39): separate QEMU-only `apic-preempt-smoke` flavor uses the xAPIC IRQ assembly stub to store the live 15-GPR/hardware interrupt frame for one non-yielding kernel task, select another validated private-stack frame and IRETQ to the other task. The two tasks NEVER voluntarily yield to each other; they must both progress under >=8 genuine IRQ-triggered switches (>=4 interrupted epochs per task). The final running task transfers ONCE back to the BSP test harness with IF=0 for teardown. Acceptance requires 1- and 4-vCPU QEMU runs, zero rejected frame bounds/selector/IF checks and complete existing regression suite. **This is a narrow smoke proof, not a production preemptive scheduler**: task creation/destruction, SMP task queues, synchronization, user mode, kernel-stack guard pages, XSAVE/FPU/SIMD, CR3/TLS, fault recovery, arbitrary interrupt nesting and cross-CPU interrupts remain pending.

P1 IRQ-safe nested preemption-disable proof (merged, PR #40): extend the isolated BSP two-task preemptive QEMU smoke with a checked atomic preemption-disable depth (host tests for nested entry/exit, underflow and overflow). Task 0 keeps interrupts enabled inside two nested critical sections; at least four APIC timer IRQs must arrive, be EOI'd and be explicitly deferred without switching tasks. Only after the final matching enable may hardware timer IRQs switch task stacks; then both non-yielding tasks progress and the existing eight-switch acceptance passes. **This guards only BSP smoke code**, not cross-CPU locking or production scheduler critical sections.

P1 BSP legacy x87/SSE save/restore (merged, PR #41): isolated `apic-preempt-smoke` mode snapshots the original BSP FX state, sets the required x87/SSE CR0/CR4 controls after CPUID FXSR/SSE2 verification, initializes independent 16-byte-aligned 512-byte FXSAVE64 images and saves/restores task-specific state on each **real xAPIC timer-triggered task stack handoff**. Two non-cooperative tasks keep distinct XMM0 low-64-bit sentinels, verified both in running tasks and in saved FX images; the original BSP state/control flags are restored before returning from the test. Gate on 1/4-vCPU QEMU runs and zero observed corruptions. **This covers legacy x87/MMX + SSE XMM images only, not XSAVE/AVX/AVX-512 or production per-task FPU ownership.**

P1 three-way preemptive round-robin smoke (merged, PR #42): extend the isolated BSP hardware APIC preemption proof from two to three independent 16 KiB kernel stacks and three FXSAVE64 contexts. Two tasks are synthesized from validated IRETQ frames; the first enters through the existing BSP context primitive. An allocation-free bounded ready-bitmask selector rotates among all three on real timer IRQs. Require >=12 involuntary handoffs, >=4 interrupted epochs for each task, <=1 maximum difference in IRQ dispatch counts, nonzero work for all tasks, 0 rejected frames, independent XMM0 sentinels with 0 corruption, unchanged nested critical-section deferral and exactly matching IRQ/EOI counts in both 1- and 4-vCPU QEMU. **This is not yet dynamic task creation, SMP scheduling, process isolation, production run queues or XSAVE.**

P1 real blocked/wake/resume lifecycle proof (merged, PR #43): the BSP-only three-task QEMU xAPIC preemption smoke now permits task1, **while actually running**, to clear its own runnable bit in an atomic checked operation with a preemption-disabled critical section. At its next real timer IRQ, task1's work count is snapshotted and its original saved RIP/RSP/GPR/FX state is parked. Other tasks must progress while >=6 more xAPIC interrupts occur, all proving the blocked task's work count remains frozen and the scheduler skips its bit. Only a timer-driven checked wake restores task1 to Ready; it must resume exactly once on the suspended kernel stack with preserved SSE XMM0. After wake, require >=4 dispatches per each of three tasks and a round-robin fairness gap <=1, while IRQ/EOI parity and all prior tests remain mandatory in 1- and 4-vCPU QEMU. **This is fixed BSP-only lifecycle proof, not a production sleep/wakeup API, general task ownership, dynamic allocation or full SMP scheduler.**

P1 Finished task retirement under real timer IRQs (merged, PR #44): task2, running on its own BSP-private kernel stack, transitions to **Finished** after the post-wake three-task round-robin proof. It atomically clears its Ready bit and sets an independent terminal-state mask under a preemption-disabled critical section, without reusing or freeing its still-live interrupt stack. Its first subsequent xAPIC IRQ snapshots the final work count; >=6 additional IRQs must prove work remains frozen, task2 is never selected again, and tasks0/1 continue receiving >=4 IRQ-scheduled dispatches each with fairness delta <=1. Pure host tests refuse re-waking or re-finishing a terminal task, last-ready termination, invalid masks or indices. Acceptance includes original x87/SSE isolation, blocked/wake/resume checks and 1/4-vCPU QEMU. **No stack reclamation, PID reuse, dynamic task creation or true production lifecycle yet.**

P1 quiescent fixed-slot recycling proof (under review): after the full three-task BSP preemption QEMU test and >=6 real IRQ observations that the Finished task2 never runs again, return to an independently measured **disjoint BSP stack with IF=0**. A generation-tagged task-slot owner denies early/active reclaim, stale handles, duplicate allocation and generation wrap; only verified quiescence permits task2 to move to Vacant. The old 16 KiB stack and 512-byte legacy FX image are explicitly wiped with volatile stores and read back. The FX image is reseeded from the saved valid original baseline, while the wiped stack receives a new, separately validated kernel-only IRETQ frame and a strictly newer generation. Its ready-mask bit remains **cleared**: the new occupant is initialized but NOT executed. Require this evidence in 1/4-vCPU QEMU and keep all existing Finished, Blocked/wake, SSE and IRQ/EOI regressions. **This recycles a static slot, not physically free-able pages, a general spawn API, a live recycled-task execution test or SMP-safe reclamation.**

P1 **still pending**: monotonic production clocksource and validated calibration across hardware, safe interrupt-frame capture/restoration, IRQ-safe preemptive scheduler with real involuntary context switches, timer lifecycle/drivers, AP-local timer/EOI handling and IPIs, coordinated full SMP scheduling, real-device regression testing. These are acceptance-gated separately.

P2 remains unimplemented: ring-3 address-space isolation, syscalls, ELF user loader/init, process lifecycle, RAM filesystem and protection checks. Later Windows/Steam compatibility work must not be confused with current kernel smoke proofs.
